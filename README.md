🔴 The Challenge: "High-Entropy" Data

Logistics data is rarely clean. This project dealt with **"Data Hell"**: unstructured logs, mismatched timestamps, and shifting columns that standard SQL/Pandas scripts couldn't parse.

The Transformation (Before vs After)

| Raw "Messy" Data (Input) | AI-Augmented Cleaning (Output) |

| *Unstructured, inconsistent formats, and high-entropy noise.* | *Structured Star Schema ready for time-series analysis.* |



🚀 Key Features

  * **Dual-SLA Logic:** Real-time comparison between **Strict SLA** (from Arrival) vs. **Fair SLA** (from Verification).
  * **Bottleneck Funnel:** Identifying exactly where shipments stall (e.g., the 4.3-day "Verification" lag).
  * **AI-Driven Recovery:** Leveraging LLMs to restructure fragmented CSV logs into actionable insights.
  * **Performance Optimization:** Implemented `@st.cache_data` for seamless interactive filtering.

💡 Key Business Insights

  * **The KPI Fallacy:** Proved that team efficiency is actually **61.8%**, despite the system reporting **38.2%** (due to a 23.6% hidden queueing gap).
  * **The "Dead Zone":** Identified Friday arrivals as high-risk, with 30% higher lead times due to weekend staffing gaps.
  * **Root Cause:** Linked 16.7% of delays to "Physical Item Mismatch", shifting focus to gate-verification accuracy.
